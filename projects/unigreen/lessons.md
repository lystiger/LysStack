# Unigreen Verified Lessons

- Keep context bundles bounded and task-relevant.
- Do not commit orchestration or handoff evidence into product repositories.
- Deterministic checks are stronger evidence than an agent saying code works.
- Provider identity and workflow role must remain separate.
- First validate orchestration on a narrow real vertical slice before adding
  dynamic planning or additional frameworks.
- Multi-agent delivery across BUILDER (Antigravity), HARDENER (Claude), and
  VERIFIER (Codex) successfully landed the core public inquiry slice without
  orchestration leaks.
- Customer-submitted inquiry data must remain immutable; operational metadata
  (internal notes, assignment, qualification status) should be stored in
  separate tables/columns to prevent commercial history distortion.
- Contract synchronization (`export_openapi.py` diff and `npm run api:types`)
  ensures frontend/backend type safety across independent worker phases.
